## 1. 目标

- `<canvas>` 盒模型
  - 知道 `<canvas>` 默认是 `300x150` 的行盒即可。

## 2. demos.1 - 理解 canvas 盒模型

::: code-group

```html [1.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    canvas {
      outline: 1px solid #ddd;
    }
  </style>
</head>
<body>
  <!--
    1. canvas 是一个行内元素
    2. canvas 默认大小是 300 * 150

    打开浏览器查看最终渲染效果会发现俩盒子同行显示。
    打开 devtools，查看盒模型，会发现盒子尺寸是 300 * 150。
   -->
  <canvas></canvas>
  <canvas></canvas>
</body>
</html>
```

:::

- 如果你仅仅创建了一个 `canvas`，但是并没有指定它的 `width`、`height`，那么这个 `canvas` 的默认尺寸是 `300 * 150`。
