## 1. 目标

- 掌握 `ctx.rotate` 的基本使用

## 2. 评价

- `ctx.rotate` 旋转的是整个坐标系。
- ![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-08-24-21-13-34.png)

## 3. `ctx.rotate`

- `ctx.rotate` 用于旋转画布的当前绘图。
- 旋转不会对之前绘制好的内容有影响。
- 旋转的角度单位是弧度。
- 旋转默认是基于画布的原点来旋转的。
- 这种旋转会影响到之后所有的绘制操作，直到画布的变换状态被重置或者再次修改。
- 每次的旋转都是基于当前的坐标轴已旋转的角度进一步旋转的。

## 4. demos.1 - 理解 `ctx.rotate` 旋转的一些特性

::: code-group

```html {20-54} [1.html]
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta http-equiv="X-UA-Compatible" content="IE=edge" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <script src="../common/drawGrid.js"></script>
    <script>
      const canvas = document.createElement('canvas')
      drawGrid(canvas, 300, 300, 50)
      document.body.append(canvas)
      const ctx = canvas.getContext('2d')

      ctx.beginPath()
      ctx.globalAlpha = 0.5

      // 绘制一个参考矩形
      ctx.fillStyle = 'red'
      ctx.rect(200, 200, 50, 50)
      ctx.fill()

      // 在执行 rotate 之前绘制的图形，不会受 rotate 影响。
      // 比如上面这个矩形。

      /**
       * 旋转次数
       */
      const rotateCount = 9

      /**
       * 每次旋转的角度，这里设置为 10°。
       */
      const angle = (10 * Math.PI) / 180

      // 旋转之前的初始状态
      // 坐标轴旋转 0°
      // 在 (200, 50) 位置绘制一个圆
      drawCircle(200, 0, 10)

      // 坐标轴旋转 10°
      // 坐标旋转 10° 再绘制一个圆
      for (let i = 1; i <= rotateCount; i++) {
        ctx.rotate(angle)
        drawCircle(200, 0, 10)
      }

      function drawCircle(x, y, radius) {
        ctx.beginPath()
        ctx.arc(x, y, radius, 0, Math.PI * 2)
        ctx.fill()
      }
    </script>
  </body>
</html>
```
